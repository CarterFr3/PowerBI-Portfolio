# Supply Chain Analysis Dashboard

## Project Overview
This Power BI project analyzes a fashion & beauty supply chain dataset. The goal is to identify cost drivers, supplier performance issues, lead time problems, and opportunities to improve efficiency.

## Business Questions Answered
- Which suppliers have the highest costs and defect rates?
- How do lead times and shipping costs impact overall performance?
- Which product types generate the most revenue vs highest costs?
- Where are the biggest bottlenecks in the supply chain?

## Skills Demonstrated
- Data modeling (Star Schema)
- Power Query data transformation
- DAX measures
- Data storytelling & visualization
